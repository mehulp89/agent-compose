# Governance

AgentCompose is currently a maintainer-led project.

The repository owner has final responsibility for releases, security response, the public API, and
Code of Conduct enforcement. Technical decisions should still be made in public issues and pull
requests whenever security or privacy does not require confidentiality.

Consistent contributors may be invited to triage issues or review pull requests. Maintainer access
is based on sustained constructive participation, technical judgment, community behavior, and a
demonstrated commitment to backward compatibility—not on the number of lines contributed.

Major changes use this lightweight process:

1. Open a proposal issue with motivation, examples, alternatives, compatibility, and security.
2. Gather community feedback.
3. Record the maintainer decision and rationale.
4. Implement through reviewed pull requests with tests and migration documentation.
